# VoiceMind - 智能语音记录与分析App

## 一、项目愿景与定位

### 1.1 产品定位
打造一款**个人AI助理型**的语音记录工具，定位为"你的第二大脑"——专注于无声记录、智能分析、按需调用，让用户不再错过任何重要信息，同时确保数据完全自主可控。

### 1.2 核心价值主张
- **隐私优先**：数据永不离开本地设备
- **无感知记录**：静默运行，精准捕获，无需手动操作
- **智能沉淀**：将碎片对话转化为结构化知识
- **零成本高配**：免费拥有大厂万元产品的核心能力

### 1.3 目标用户画像
| 用户类型 | 核心场景 | 痛点 |
|---------|---------|------|
| 职场人士 | 会议纪要、客户沟通、学习培训 | 手动记录繁琐、遗漏关键信息 |
| 销售人员 | 客户跟进、需求挖掘、承诺记录 | 事后回忆失真、承诺遗漏 |
| 学生群体 | 课堂笔记、导师指导、小组讨论 | 信息量大、难以抓住重点 |
| 媒体从业者 | 采访录音、素材积累 | 整理耗时、检索困难 |
| 创业者 | 灵感记录、商务谈判、团队沟通 | 碎片化信息难整合 |

## 二、核心功能深化与扩展

### 2.1 智能录音系统

#### 基础能力
| 功能点 | 详细描述 |
|--------|----------|
| **多模态触发** | 支持声音阈值触发、关键词触发、位置触发（进入/离开特定地点）、定时触发 |
| **智能降噪** | 环境音分离，保留人声主体，区分说话人 |
| **多源录音** | 支持外接麦克风、耳机麦克风、蓝牙设备，满足不同场景需求 |
| **分段管理** | 自动根据沉默间隔、说话人变化、时间长度进行分段 |
| **录音质量** | 支持标准（64kbps）/高清（128kbps）/无损（256kbps）三档可调 |

#### 场景化录音模式
- 📞 电话录音模式：自动检测通话状态，区分本端/对方声音
- 👥 会议录音模式：360°环形收音，标注说话方位
- 🎤 采访录音模式：单点聚焦，背景音抑制
- 🌙 夜间/安静环境：超低功耗静默监听，仅保留关键词唤醒

### 2.2 AI实时分析与处理

#### 对话理解维度
| 分析类型 | 具体内容 |
|----------|----------|
| **内容转写** | 高准确率语音转文字，中英混合、方言支持、专业术语识别 |
| **情感分析** | 情绪标签（正向/中性/负向）、情绪波动曲线、关键情绪节点 |
| **主题提取** | 自动识别对话主题、涉及领域、讨论深度 |
| **任务识别** | 提取待办事项、承诺承诺、约定时间、涉及人物 |
| **观点归纳** | 提取各方观点、共识点、分歧点、决策结论 |
| **术语解释** | 自动识别专业术语，提供简要解释（可配置） |

#### 智能总结能力
- 📊 实时摘要：对话进行中实时生成要点卡片
- 📝 深度总结：对话结束后生成结构化报告
- 📅 周期回顾：周/月/季自动生成对话分析报告
- 🔗 关联分析：跨对话提取同一主题的演变历程

### 2.3 知识管理系统

#### 人物画像构建
- 👤 基础信息：姓名、职位、关系、首次接触场景
- 📋 交互记录：该人物所有对话时间线、关键内容
- 🎯 需求洞察：历史对话中表达的需求、偏好、痛点
- 🤝 承诺追踪：对其做出的承诺及完成状态
- 💬 沟通风格：语言习惯、关注点、敏感话题

#### 事件时间线
- 📅 事件卡片：主题、参与人物、发生场景、关键结论
- 🔗 事件关联：自动关联相关人物、任务、地点
- 📈 事件演进：跟踪长期事件的进展变化
- 🔔 事件提醒：基于对话内容自动生成后续跟进提醒

### 2.4 AI对话助手（增强版）

#### 带上下文的智能问答
| 功能 | 描述 |
|------|------|
| **语义检索** | 自然语言提问，快速定位相关对话片段 |
| **多轮追问** | 支持基于上一轮回答继续追问 |
| **时间范围限定** | 可指定"上周""上个月""与某人的所有对话" |
| **来源追溯** | 每个回答标注来源对话，可一键回听原音 |
| **多知识库整合** | 支持对话知识、人物信息、事件记录的联合查询 |

#### 专属助理模式
- 💼 工作模式：专注职场沟通、项目进展、会议决策
- 💬 社交模式：辅助回顾与人际关系维护
- 📚 学习模式：课程内容总结、知识点回顾
- 🧘 情绪模式：情绪曲线分析、压力预警

### 2.5 智能提醒与待办系统

#### 自动提取待办
- 承诺类："我周五前给你发报价" → 自动生成周五提醒
- 任务类："这个需求下周要上线" → 下周一提醒
- 跟进类："客户说考虑一周" → 一周后提醒并关联客户档案
- 约定类："我们下周再聊" → 自动添加到日程

#### 提醒管理
- 支持系统日历同步
- 支持钉钉/飞书/企业微信任务同步（可选）
- 提醒优先级自动判定（紧急/重要/常规）
- 提醒升级机制（未完成自动延期并加大提醒力度）

## 三、技术架构与隐私安全

### 3.1 系统架构设计

```
┌─────────────────────────────────────────────────────────┐
│                      手机端 App                          │
│  ┌─────────┐  ┌─────────┐  ┌─────────┐  ┌─────────┐   │
│  │录音引擎 │  │本地缓存 │  │权限管理 │  │设备配对 │   │
│  └─────────┘  └─────────┘  └─────────┘  └─────────┘   │
└─────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────┐
│                    电脑端客户端                          │
│  ┌─────────┐  ┌─────────┐  ┌─────────┐  ┌─────────┐   │
│  │数据接收 │  │本地向量 │  │AI模型   │  │加密存储 │   │
│  │与服务   │  │数据库   │  │调用引擎 │  │引擎     │   │
│  └─────────┘  └─────────┘  └─────────┘  └─────────┘   │
└─────────────────────────────────────────────────────────┘
```

### 3.2 隐私安全措施

| 层级 | 措施 |
|------|------|
| **传输层** | WiFi直连/USB传输，不经过第三方服务器 |
| **存储层** | AES-256加密存储，密钥基于设备指纹生成 |
| **访问层** | 生物识别（指纹/面容）+ PIN码双因子认证 |
| **使用层** | 录音文件本地处理，原始音频不离开设备 |

## 四、性能指标

| 指标 | 要求 |
|------|------|
| 录音延迟 | < 100ms |
| 转写延迟 | < 3秒/分钟音频 |
| 启动时间 | < 2秒 |
| 内存占用 | < 150MB（手机端）|
| 电量消耗 | < 5%/小时（录音状态）|
| 存储效率 | 1小时音频 ≈ 30MB（压缩后）|

### 兼容性要求
- 📱 手机端：Android 9.0+
- 💻 电脑端：Windows 10+ / macOS 11+
